### Olá, seja bem vindo! 👋


###### Sobre a Julia
Atuo no desenvolvimento de aplicações full stack, participando de todo o ciclo de desenvolvimento — desde a criação de interfaces até a integração com APIs e serviços back-end. Tenho foco na construção de código limpo, escalável e reutilizável, sempre priorizando boas práticas e performance.

Trabalho com TypeScript, React e Vue.js no front-end, além de desenvolvimento back-end com Node.js e Java, criando e consumindo APIs REST. Também aplico testes automatizados com Cypress para garantir a qualidade das aplicações.

Estou sempre em busca de novos aprendizados e aberta a novas oportunidades na área. 🚀
